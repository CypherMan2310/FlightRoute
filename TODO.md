## How to run
- Tests: `cd backend && python -m pytest` (offline, about 320 tests, ~20 s). Frontend: `cd frontend && npm ci && npm run build`.
- App: `make build` then `make run` (API + UI on :7860), or `make dev` + `cd frontend && npm run dev`.
- Models: `backend/models` holds the trained bundle. Retrain after any change to a feature list or artifact format (`tests/test_committed_models.py` fails until you do): `make train-real` (slow, resumable, see train.yml) or `make train-synth` (smoke, temp dir).
